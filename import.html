Import old SMS

1. Export your messages

  1. Install SMS Backup & Restore (by SyncTech) from the Play Store.
  2. Open it, tap Set up a backup, turn Messages on and Phone calls off. Under Advanced options, turn off MMS (photos make the file huge).
  3. Choose Your phone as the backup location, then Back up now.
  4. It saves a file like sms-20261020….xml in the SMSBackupRestore folder on your phone.

2. Choose that file

The file is read on this phone. Only messages with an amount in SAR or INR are sent to your site; personal chats stay on your phone.
